# Portfolioo 🌐

A modern, responsive **portfolio website** built with plain HTML, CSS & JavaScript — no frameworks, no build step required.

## ✨ Features

- 🎨 Clean, modern UI with smooth animations
- 🌓 Dark / Light theme toggle (remembers your choice)
- 📱 Fully responsive — works on mobile, tablet & desktop
- ⌨️ Animated typing effect in the hero section
- ✍️ Working contact form (front-end validation)
- 🖱️ Custom cursor + scroll-reveal animations
- ⚡ Lightweight and fast — zero dependencies

## 🚀 Quick Start

Just open `index.html` in your browser — that's it!

Or serve it locally with VS Code **Live Server** for the best experience.

## 🛠️ Customization

All content lives in `index.html`. Update these to make it yours:

| What | Where |
|------|-------|
| Name, titles, bio | `index.html` → hero & about sections |
| Skills | `index.html` → skills section |
| Projects | `index.html` → projects section |
| Email / location / socials | `index.html` → about + contact sections |
| Colors & theme | `css/style.css` → `:root` variables |

## 📂 Structure

```
Portfolioo/
├── index.html      # Main page
├── css/
│   └── style.css   # All styles + theme variables
└── js/
    └── script.js   # Theme, nav, typing, animations
```
